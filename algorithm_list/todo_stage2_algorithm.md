## A2.3 实现模拟时钟 约 2 小时

- [ ] 给模拟任务添加到达时间与服务时长，模拟到达、选择、执行和空闲。

动文件：`scheduler/simulator.py`，复用 `scheduler/fcfs.py`；用 `scripts/demo_simulation.py` 组织例子。  
做法：只向 FCFS 提供已到达任务；无就绪任务时跳到下次到达；选中后按服务时长推进时钟。字段名与单位见共同约定。  
检查：执行 `python3 -m scripts.demo_simulation` 可看到每个任务的到达、开始、结束时间；不提前执行，模拟器按数字推进时钟，无需真实休眠。

## A2.4 用手算验证模拟器 约 1.5 小时

动文件：在 `scripts/demo_simulation.py` 放两组固定输入，在 `docs/stage2_algorithm.md` 写预期与实际结果，修正 `scheduler/simulator.py`。  
检查一：T1、T2、T3 均在 0 毫秒到达，依次耗时 300、100、200，预期开始为 0、300、400，结束为 300、400、600。

## A2.5 计算指标并导出 CSV 约 1.5 小时

检查：等待 = 开始 − 到达，周转 = 结束 − 到达；案例一等待为 0、300、400，周转为 300、400、600，案例二等待均为 0。空列表平均值记无数据；字段、毫秒单位和 `data_source=simulation` 与共同约定一致。
